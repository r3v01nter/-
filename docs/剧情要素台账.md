# 剧情要素台账

> 用途：记录正文已经明确写出的事实、角色当前掌握的信息、物件流转、时间关系与尚待回收的线索。
>
> 规则：
> - **正文事实**与**角色判断**分开记录；角色的推测不自动成为世界真相。
> - “待核实”不等于剧情错误；“待回收”不等于必须按预设答案回收。
> - 新增或改变既有设定时，先记入作者裁决与设定变更日志，再更新本台账。
> - 本文件基于当前仓库可见正文建立。尚未逐章核验的细节标注为“初步记录”，后续以正文复核为准。

### 时间线处理原则

1. 现阶段不擅自把“T-04 第三日”改成其他日期，也不将其判为硬伤。
2. 下一次核对时，优先逐章摘录明确的“次日、三日后、五天后、第七天”等时间词，建立统一的相对日序。
3. 若正文故意采用模糊时间，应保留模糊；只有在行动顺序或人物状态发生冲突时才提出局部修订。

## 五、已确认的审稿处理决定

1. **第十章旧档材料交接表达：优先核实。** 第九章女子提供的是“公开记录的索引”；第十章匿名来客口称“旧档索引”，实际送来的是两页旧案抄录和一块矿石。该差异可以是人物有意误导，但正文应让读者能意识到沈砚注意到了这个差异，不能仅靠读者自行补洞。
2. **相对时间线：建立台账，不立即改正文。** 优先核对第一至第十章明确时间词，之后再决定是否需要一处或数处局部澄清。
3. **润色范围：暂缓大规模改写。** 先处理事实连续性、物件交接和证据边界；文风重复只做必要局部调整。
4. **线索之间默认独立。** 只有出现可验证的共同证据后，才将不同事件归并为同一因果链。

## 六、后续维护格式

每完成一轮章节审稿，按以下格式追加或更新：

- **新事实：** 正文明确发生的事件。
- **角色认知：** 哪个人知道什么、相信什么、误以为什么。
- **物件变动：** 物件从谁转到谁，是否验证、是否遗失。
- **时间锚点：** 明确日期词及参照事件。
- **待回收线索：** 当前证据、缺失证据、可能的回收窗口。
- **作者裁决：** 只有用户明确确认的设定变更才写入已确认项。
