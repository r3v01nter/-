# 我在修仙界做实验

**修仙可以靠天赋，也可以靠实验。至于人心和世界，没那么容易算明白。**

沈砚只有五灵根，修炼效率低；他不靠天降外挂，而是从一次次失败里研究五行核心。故事从他已经成为“清醒的坏人”时开始：他曾亲手把一位保护凡人的正道天骄推向死亡，如今却带着遗体走回对方宗门。

## 写作原则

1. 主角谨慎、冷酷，但不全知；谋划必须有信息来源、成本和失败风险。
2. 五行核心是研究成果，不是无代价的天赐外挂。
3. 思想与制度变化从实践、生产力、资源分配和权力关系中展开。
4. 四位核心女主拥有独立目标，不因感情自动原谅主角。
5. 量劫由自然变化与文明冲突共同推动，不把所有灾难都归给幕后黑手。
