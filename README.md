## 写作原则

1. 正文从主角已经成为“清醒的坏人”的阶段开始，过去通过线索逐步揭露。
2. 主角谨慎、冷酷，但不全知；行动必须有信息来源、成本与失败风险。
3. 五行核心是主角研究失败后逐步建立的成果，不是无代价的天赐外挂。
4. 社会与制度变化从具体实践、生产力、资源分配和权力关系中展开，不靠角色长篇讲课。
5. 四位核心女主拥有独立目标与判断，不为恋爱自动原谅主角。
6. 核心主题：**他不是来替这个世界永远掌火的。他是来让这个世界学会生火的。**
